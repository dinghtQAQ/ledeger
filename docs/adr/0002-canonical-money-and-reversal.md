# 以四位小数金额作为记账事实并使用冲正修正

**Status: accepted**

金额以人民币正数表达，最多保留四位小数；超过四位时按半入规则归一化，计算使用归一化后的记账金额，展示时再按半入规则显示三位小数。金额错误不通过通用编辑覆盖，而是保留原账目并执行一次等额反向冲正，使原账目与修正账目的合计严格为零。这样可以把“显示精度”和“业务精度”分开，也能保证未来拆分或合并时不因展示舍入而改变真实合计。

## Consequences

- 输入金额必须是十进制字符串，不能依赖 JavaScript 浮点数表达。
- 原始超过四位的小数不作为独立原始值保留。
- 冲正是业务修正，不是物理删除；同一账目不能重复冲正。

# 以 Worker 配置控制访问并统一时间边界

**Status: accepted**

这是单用户工具，但业务接口仍必须使用 Worker 的密钥或变量鉴权，鉴权失败统一返回 `403`；健康检查和 API 文档保持公开。数据库时间统一保存为 UTC，日期筛选按 `LEDGER_TIMEZONE` 解释，默认使用东八区。写入使用幂等键，更新采用乐观并发控制，查询使用游标分页并支持日期、分类和排序筛选。这样把个人部署的秘密留在运行环境，同时让数据库查询和接口行为有稳定的时间与写入边界。

## Consequences

- 密钥、时区和生产绑定不写入公共源码配置。
- 查询客户端不能假设数据库保存的是本地时间。
- 备份、导出和前端体验暂不属于该边界。
